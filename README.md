# 審判相性チェッカー

Jリーグの過去3年間の試合データをもとに、指定したチームと審判の組み合わせにおける試合結果を確認できるWebアプリケーションです。

## 開発背景

Jリーグファンの間では、チームの成績や選手のデータ、過去の対戦成績など、さまざまな統計情報への関心が高いです。

一方で、試合の判定をめぐって審判が話題になることも多く、ファンにとって審判は試合を見る上で関心の高い要素の一つです。

そこで、特定のチームと審判の組み合わせに着目し、過去の試合結果から相性を確認できるアプリがあれば面白いと考え、開発しました。

## 主な機能

* チーム・審判・期間を指定した試合検索
* 指定したチームと審判の組み合わせによる試合結果の集計
* 勝敗・得点・失点などの統計情報の表示
* 検索条件の保持
* 検索結果に該当する試合の一覧表示

## 画面

### 検索画面

チーム、審判、期間などの条件を指定して試合を検索します。

### 検索結果画面

指定した条件に該当する試合結果と、勝敗・得点・失点などの統計情報を表示します。

## 工夫した点

### 試合データをもとにした統計情報の集計

指定したチームと審判の組み合わせに該当する試合データをもとに、勝敗・得点・失点などを集計して表示しています。

### 検索条件の保持

検索画面から結果画面へ移動した後も、検索条件を保持できるようにしています。
